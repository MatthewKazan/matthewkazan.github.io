LiDAR SLAM · Measured depth

iPhone LiDAR SLAM

Northeastern University · Robotics

Walk around a room with the iPhone app and its LiDAR measures the surfaces around you. I built the Swift scanner and ROS 2 pipeline that assemble those measurements into a 3D map.

Project code and notes Try the browser demo

From a sensor reading to a registered scan

The app uses ARKit depth and camera intrinsics to back-project each frame into 3D points. I stream the points to ROS 2 and record them in bags so I can rerun the same walk with different registration settings.

Each new scan is aligned against the local map to estimate where the phone moved. I built a common registration interface to compare ICP and Deep Global Registration on the same point clouds.

Recognizing a place the phone has already seen

Small alignment errors accumulate as the scan grows. Scan Context and NDT-Transformer descriptors propose matches to earlier views, and geometric verification checks whether the scans line up. I add the verified constraints to a GTSAM factor graph and use the optimized poses to rebuild the map.

Browser Camera mode builds a rough map from estimated depth.

The browser gets RGB video. The native Swift app reads the iPhone’s LiDAR and uses measured depth for mapping.
