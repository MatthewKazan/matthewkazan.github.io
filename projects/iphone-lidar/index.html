iPhone LiDAR SLAM

Northeastern University · Robotics

I built a Swift app that streams measured iPhone LiDAR points to ROS 2. The backend estimates the phone’s motion and adds each registered scan to a global 3D map.

Project code and documentationTry the browser demo

Capture and scan registration

ARKit supplies depth and camera intrinsics. The app back-projects the depth map and streams 3D points to separate ROS 2 capture and processing stages. Saved rosbags make it possible to replay a scan with the same inputs while changing registration settings.

I implemented configurable registration and descriptor interfaces and evaluated ICP and Deep Global Registration on point clouds.

Loop closure and map correction

Scan Context and NDT-Transformer descriptors suggest revisits. Geometric verification supplies relative pose measurements. The resulting GTSAM factor graph uses odometry and loop constraints to refine the phone’s trajectory with Levenberg–Marquardt.

Browser Camera mode is approximate. The website receives only RGB video and estimates depth. The native app uses measured LiDAR depth.
