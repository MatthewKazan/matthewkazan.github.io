Wireless Fencing Scoring

Personal project · December 2020

I fence épée and wanted a portable way to keep score. I prototyped wearable touch detectors and built a Swift app to run the clock and keep track of the bout.

Hardware and firmware repository

Touch detection hardware

Each detector plugs into a standard épée body cord. I designed the ESP32 sensing circuit with a buzzer and LED for touch feedback, wrote the firmware, and modeled a wearable enclosure for 3D printing.

Scorekeeping interface

I built a Swift interface for reading and editing scores through Firebase Realtime Database. Getting a touch from the blade to the screen meant debugging the circuit, timing, and software together.
