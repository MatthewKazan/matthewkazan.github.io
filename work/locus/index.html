Locus Array

Motion-capture ground truth

I built a framework to evaluate six-degree-of-freedom localization and positioning. SVD plane fitting establishes a reference surface, swing–twist decomposition separates tilt and heading, and left-invariant pose error measures deviation. The system reports uncertainty, bias, repeatability, and spatial error in an internal web app in near real time.

Simulation infrastructure

I integrated simulated IMU, odometry, camera, LiDAR, and transform data with the production localization stack in Gazebo and ROS 2 Jazzy. I designed the Docker setup for local and cloud runs, with pytest regression tests, gz-web integration, and a common CLI.
