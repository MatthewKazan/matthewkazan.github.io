How closely does a warehouse robot’s estimated pose match where it actually is? I build the ground-truth and simulation tools that help us answer that for mobile manipulators and track down the source of the error.

Locus Array

Measuring localization and positioning

I built a six-degree-of-freedom motion-capture reference to evaluate localization and positioning. I fit reference planes with SVD, separate tilt from heading with swing–twist decomposition, and compute left-invariant pose error to compare the robot’s pose with ground truth.

I put the results into an internal web app so the team can see uncertainty, bias, repeatability, and where errors occur on the floor as we run tests.

Running the production stack in simulation

I integrated simulated cameras, LiDAR, IMU, odometry, and frame transforms with production localization in Gazebo and ROS 2 Jazzy. I set up Docker for local and cloud runs and built pytest regressions, a shared CLI, and a browser view through gz-web.

I also worked on bringing a simulated arm into the stack, including how to model its perception inputs and connect its controls.
